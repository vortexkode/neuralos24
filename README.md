# NeuralOS — Marketing Site

The public marketing/landing page for **NeuralOS** (by VortexKode) — a focus/deep-work timer app that turns session history into a growing neural visualization and, for Pro subscribers, decodes behavioral patterns via the Pattern DeKoder.

## What's here

- `index.html` — the entire site. Single file, no build step, no framework — plain HTML/CSS/JS, real screenshots and screen recordings from the actual app.
- `assets/` — the real screenshots and videos the page references. Nothing fabricated; every screen shown is the real app.

## Deploying

This repo is served directly via **GitHub Pages** from the `main` branch. Any push to `main` goes live at the Pages URL within a minute or two — there's no separate build step.

## Editing

Just edit `index.html` directly and push — it's a static file, what you see is what ships.
